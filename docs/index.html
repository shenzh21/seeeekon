03 / 留在本机

熟悉，且简单

对话保存在本机，密钥加密保存。支持对话置顶、深色模式和历史备份。

几步，就能开始。

首次连接可能需要登录两次：
开放平台连接账户，聊天网站导入历史。

  1. 下载 APK，按 Android 的提示允许浏览器安装。
  2. 打开 App，点“连接 DeepSeek”，按提示登录开放平台并创建本设备专用密钥。
  3. 选择是否导入旧对话。需要导入时，再登录 DeepSeek 聊天网站。
  4. 余额不足时，从侧栏进入“DeepSeek 官方充值”。
