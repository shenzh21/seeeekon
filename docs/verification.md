## 实际网页与上游

在本机浏览器测试 1280×800 桌面和 390×844 手机视口。手机页面 scrollWidth 与 innerWidth 均为 390，没有横向溢出。截图为 `desktop-preview.jpg` 与 `mobile-preview.jpg`。

- `.env` 的 OPENCODEGO_API 成功调用 Go 的 DeepSeek V4.1 Flash。密钥未打印，浏览器通过本地服务调用。
- 普通聊天请求得到“你好，欢迎回来。”；默认余额从 ¥2.00 到 ¥1.99。模拟充值 ¥20 后 ¥21.99，有对应收支记录。
- 开启深度思考，17×23 返回思考块及 391；关闭后普通回复正常。
- 长文请求点击停止后立即结束，显示可重新生成/继续生成，余额没有因停止请求减少。
- 使用 `scripts/make-fixture.mjs` 生成的官方 v3 格式 ZIP 导入，已有对话仍保留。样例约定灯塔名为“白鹭”；导入后提问得到“白鹭”，证明实际上下文随请求进入模型。
- 刷新后历史、已追加消息和余额保留。重复导入原样例后仍只有原有两个会话，追加的提问和回答保留。
- 导入损坏 ZIP 显示错误，原有会话和追加消息未改变。
- 自备 API 模式选择刷新后保留，未填写 Key 时进入高级设置；恢复默认后刷新不再要求 Key，发送消息成功。
- 新建会话使用首条提问作标题；未提供 Go 不支持的自动标题参数。

上游网页工具、附件、语音在默认模式下不展示入口；没有用空按钮代替实现。自备接口仅验证配置持久化和恢复默认，没有持有另一服务的凭证进行真实调用验证。
